ทีมงานจะตรวจก่อนขึ้นร้าน ปกติไม่เกิน 1–2 วัน

index.html ไฟล์เดียวไม่เกิน 10 MB ใส่ JS, CSS และรูปไว้ในไฟล์เดียวกัน (รูปแปลงเป็น data URI)
ภาพปกPNG, JPEG หรือ WebP ไม่เกิน 2 MB แนะนำ 1600×1000
ห้ามใช้เครือข่ายแอปบล็อกทุก request ออกนอกเครื่อง fetch, WebSocket และ URL ภายนอกจะถูกแจ้งเตือนตอนตรวจ
เล่าว่ามันตอบสนองต่อเมาส์อย่างไร คลิกแล้วเกิดอะไรขึ้น ไม่เกิน 2,000 ตัวอักษร
คั่นด้วยจุลภาค ไม่เกิน 8 แท็ก แท็กละไม่เกิน 24 ตัวอักษร
